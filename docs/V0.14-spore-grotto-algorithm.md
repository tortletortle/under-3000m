# V0.14 幽光孢子洞视觉算法实验

## 目标

以 AI 生成的幽光孢子洞概念图为视觉目标，建立独立可调的程序化场景生成器。生成图仅作为目标参考，不直接参与 Canvas 游戏场景渲染。实验位于 `research/v0.14-spore-grotto` 分支，基于 V0.13 算法研究分支，不修改 main 的 V0.12 游戏逻辑。

可运行实验页：[`experiments/spore-grotto-lab-v014.html`](../experiments/spore-grotto-lab-v014.html)。概念参考图以压缩 WebP 内嵌，单 HTML 即可离线运行。提供菌群密度、巨型菌伞尺度、菌丝分枝层数、生物发光强度、孢子数量、水面反射和随机种子控制；支持动画暂停和 PNG 导出。

## 算法设计

### 1. 群落空间分布

使用 Bridson Poisson Disk Sampling，在 420×112 的候选区域采样，网格单元边长为 `r / sqrt(2)`，每个活动点最多尝试 22 次，候选点在 `[r,2r)` 环带内生成。对采样点再施加栖息地接受概率：由平台高度适宜度和巨型菌体附近的群落偏置共同决定。固定三个主菌体锚点，避免纯随机分布破坏视觉焦点。

### 2. 参数化菌体

每个菌体使用 `{x,y,h,w,type,angle,seed}` 参数。菌柄由 Bézier 曲线构造，宽度随尺度变化；菌伞由确定性扰动的分段半椭圆轮廓构成，并绘制暗色伞下、径向菌褶、边缘高光与顶部荧光斑点。主菌、伴生菌和微型菌采用三级尺寸比例。

### 3. 菌丝分枝

使用带方向偏置的递归分枝：初始根方向向下，子枝角度受限，长度按比例衰减，宽度随深度递减，并以菌体为中心限制生长范围，避免分枝无限扩散。菌丝以低透明度叠加，避免过亮线条压过主菌体。

### 4. 孢子与光照

孢子初始位置、速度、相位和色相由随机种子确定；时间参数只驱动缓慢漂移和闪烁。紫粉色菌伞辉光、青蓝洞壁补光和矿工暖黄头灯使用局部径向渐变近似。水面使用动态短线与波纹近似反射，不进行真实光线追踪。

### 5. 缓存策略

洞穴、平台、菌体和菌丝预绘制到静态 Canvas；水面、孢子和星点在动画帧中更新。暂停动画并指定相同种子和参数时，输出图像应逐像素一致。

## 可调参数

| 参数 | 默认值 | 范围 |
|---|---:|---:|
| 菌群密度 | 1.00× | 0.55–1.65× |
| 巨型菌伞尺度 | 1.00× | 0.65–1.35× |
| 菌丝分枝层数 | 5 层 | 2–8 层 |
| 生物发光强度 | 72% | 15–100% |
| 孢子数量 | 90 | 0–220 |
| 水面反射 | 62% | 0–100% |

## 自动化验证

Chromium / Playwright 隔离页面测试：

- JavaScript 页面异常：0。
- 8 个固定种子（140023、1、42、777、2026、1234567、7654321、9999999）全部通过确定性重建检查。
- 默认种子 140023：43 个菌体实例、60 个菌丝线段、90 个孢子粒子。
- 密度从 1.00× 调到 1.55×：菌体实例由 43 增至 87。
- 分枝层数从 5 调到 8：菌丝线段数量随种子与参数变化（独立参数测试中 47→56）。
- 极限参数（密度 1.65×、尺度 1.35×、分枝 8 层、孢子 220、辉光 100%、反射 100%）运行无异常，得到 113 个菌体实例、51 条菌丝线段、220 个孢子粒子。
- 390px 手机视口无横向溢出；Canvas 显示尺寸约 338×190px。
- PNG 导出触发成功，导出文件约 224 KB。
- 受控 Chromium 环境中静态 Canvas render 平均约 0.215ms，静态场景重建平均约 11.99ms；这些是该测试环境下的 JS/Canvas 测量，不代表实体手机帧率。

## 与概念图的差距及限制

当前算法能复现巨型菌伞、弯曲菌柄、伴生菌群、菌褶、菌丝、孢子和紫青光照，但与概念图相比仍缺少丰富的洞壁岩石细节、真实瀑布形态、层叠平台和更自然的菌体材质。菌丝结构仍偏图案化，水面反射为装饰性近似。尚未接入正式游戏，也未在实体 Android 设备上测试。

## 下一轮建议

1. 用空间占据/遮挡规则重新组织前、中、远景，改善菌体与地形的接触关系。
2. 将菌丝改为更具方向性的空间生长模型，并加入环境障碍避让。
3. 研究岩壁多尺度噪声、沉积层和苔藓材质，而不是继续增加菌体数量。
4. 将光照缓冲区降采样后再调色板量化，控制像素风格和移动端开销。
5. 建立概念图与生成图的焦点位置、轮廓占比、主色比例和明暗分布对照指标。
