# V0.13 青晶森林视觉算法实验

## 目的与隔离策略

本实验将 AI 生成的青晶森林概念图作为视觉目标，不把生成图直接贴进游戏。先抽取可重复的视觉规则，建立独立 Canvas 实验页；验证后再考虑将模块回灌主游戏。实验位于 `research/v0.13-crystal-cave` 分支，不修改 main 的 V0.12 游戏逻辑、地图、碰撞或存档。

可运行页面：[`experiments/crystal-cave-lab-v013.html`](../experiments/crystal-cave-lab-v013.html)。页面内嵌概念图缩略参考，支持调整晶簇密度、晶体尺度、发光强度、水面反射、粒子数量与粒子漂移；可更换随机种子并导出 PNG。

## 从概念图抽取的视觉结构

1. 构图锚点：左侧次晶簇、中央小晶簇、右侧主晶簇和边缘次晶簇。先控制视觉焦点，再引入确定性扰动，避免纯随机导致主体失焦。
2. 晶簇层级：主晶、伴生晶、碎晶三层；同一簇共享基线，尺寸随角色权重和与锚点的距离变化。
3. 环境纵深：远景岩层、顶壁钟乳石、远古拱桥与瀑布、中景平台、前景岩壁分层绘制。
4. 色彩与照明：青蓝主题调色板，晶体多切面分色；径向渐变以 lighter 叠加模拟局部辉光；矿工头灯使用暖色光锥形成冷暖对比。
5. 水面：从缓存场景逐行反向取样，按时间和行位置施加正弦水平偏移，再叠加波纹与瀑布飞沫，模拟反射而不进行真实光线追踪。
6. 氛围：确定性漂浮粒子、菌类小光点与瀑布高光，避免依赖随机帧造成闪烁。

## 核心算法

### Bridson Poisson Disk Sampling

- 网格单元边长：`r / sqrt(2)`。
- 活跃列表随机选点，每个活跃点最多尝试 18 次，在 `[r, 2r)` 环带生成候选点。
- 检查邻域网格，拒绝与已有采样点距离小于 r 的候选点。
- 采样点仅决定伴生晶体的位置，不决定主构图锚点。

### 参数化晶体

每个晶体由 `{x, y, w, h, lean, seed}` 描述。以尖端、左右肩点和中段节点构造多边形，再分成左右明暗切面、顶部高光面和内部裂纹线。主晶高度由锚点角色权重控制；伴生晶根据 Poisson 点与锚点的距离衰减。

### 渲染与缓存

静态岩层、桥梁、平台、晶体和矿工绘制到离屏 Canvas 并缓存；动态水面、瀑布、粒子和光晕在帧循环中叠加。这样避免每帧重复生成多边形与随机布局。

## 可调参数

| 参数 | 默认值 | 用途 |
|---|---:|---|
| 晶簇密度 | 1.00× | Poisson 区域半径、采样间距与碎晶数量 |
| 晶体尺度 | 1.00× | 主晶和伴生晶高度、宽度 |
| 发光强度 | 72% | 晶体径向光晕 |
| 水面反射 | 68% | 反射透明度与扰动幅度 |
| 漂浮粒子 | 48 | 粒子数量 |
| 粒子漂移 | 45% | 粒子水平摆动幅度 |

## 自动化验证

Chromium / Playwright 隔离页测试结果：

- 页面脚本错误：0。
- 默认种子 300013：4 个主晶簇、56 个 Poisson 采样点、106 个晶体实例。
- 晶簇密度调至 1.45×：279 个晶体实例，参数会改变生成结果。
- 相同种子、相同参数并暂停动画后，重建前后 Canvas 数据 URL 一致，确定性检查通过。
- 更换种子到 777 后标签更新；PNG 导出按钮触发下载。
- 390px 视口下 Canvas 显示尺寸约 346×194.6px，布局无横向溢出迹象。
- 默认场景单次 Canvas 绘制测量约 0.2–0.4ms；该值不等同于设备 FPS，也不包含浏览器合成与显示。

## 当前不足与下一轮实验

当前版本已验证“构图锚点 + Poisson 晶簇 + 多切面晶体 + 假反射”的工程可行性，但画面仍明显低于概念图：顶壁和拱桥结构偏几何化，岩石纹理颗粒不足，主晶簇的空间层次和瀑布细节仍需提升。当前仅为独立算法原型，未合并到正式游戏，也未在实体 Android 设备上验证性能。

下一轮应优先：

1. 用多尺度噪声与轮廓距离场生成非均匀洞壁，而不是均匀钟乳石三角形。
2. 将桥梁从单层矩形+拱洞升级为分段石砌拱桥文法。
3. 为水晶切面引入环境遮蔽近似、边缘高光和晶体内部折射纹理。
4. 使用低分辨率光照缓冲区与调色板量化，控制发光成本并保持像素风格。
5. 以概念图为目标，建立轮廓、主色比例、焦点位置和明暗分布的对照指标。
