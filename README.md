## 目标 / 架构 / 运行方式

《地下三千米》（Deep 3000）是一个 2D 像素风地下探索与采矿游戏，单文件 HTML/CSS/JavaScript 实现。V0.8 的完整可玩源码位于 [`index.html`](index.html)，使用现代浏览器直接打开即可，无需构建或安装依赖。支持键盘及移动端触屏操作。

已包含随机地下世界、挖矿及装备升级、动态地质、地下生态、遗迹、供电与自动化设施、传送带、冶炼、装配和科技解锁。此前版本报告记录了程序断言、浏览器与模拟存档迁移测试；本次迁移仅验证源码一致性，未重新运行这些测试。长期经济平衡、真实设备存档和完整通关尚待验证。
