## 目标 / 架构 / 运行方式

《地下三千米》（Deep 3000）是一个 2D 像素风地下探索与采矿游戏，单文件 HTML/CSS/JavaScript 实现。V0.11 的完整可玩源码位于 [`index.html`](index.html)，使用现代浏览器直接打开即可，无需构建或安装依赖。支持键盘及移动端触屏操作。

已包含随机地下世界、挖矿及装备升级、动态地质、地下生态、遗迹、供电与自动化设施、传送带、冶炼、装配和科技解锁。此前版本报告记录了程序断言、浏览器与模拟存档迁移测试；本次迁移仅验证源码一致性，未重新运行这些测试。长期经济平衡、真实设备存档和完整通关尚待验证。

## V0.11 验证记录

重绘四种奇观的缓存 Canvas 背景：远近岩壁、骨骼细节、水晶切面、菌盖与孢子、城市建筑层次；加强局部发光与动态微粒。保留 V0.10 地图、玩法和存档键。Chromium 隔离测试：8 个种子、32 座洞窟、154 项断言；每个种子的地图与两组流体数组和 V0.10 一致，渲染前后玩家、地图、迷雾与流体质量不变；模拟 V0.10 存档恢复与 390px 视口尺寸通过，无页面脚本异常。缓存后同步 render 中位耗时约 0.35ms（不含浏览器合成与显示；非实际帧率）。测试注入角色位置、暂停实时物理并揭开迷雾以截图，未验证完整游戏流程或真实移动设备性能。实机画面仍与概念图有差距。
